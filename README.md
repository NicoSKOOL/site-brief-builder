# Site Brief Builder

Make Claude write SEO for your business, not a generic one.

A free Claude skill from the [AI Ranking community](https://skool.com/ai-ranking-free).

## What it does

1. Reads your website and asks you the questions that matter (services, areas, customers, competitors, proof).
2. Saves everything in one `site-brief.md` file.
3. Every other AI Ranking skill reads that file, so its output is about your business instead of generic advice.

## Install

**Claude desktop app or claude.ai:** download [site-brief-builder.zip](https://github.com/NicoSKOOL/site-brief-builder/releases/latest/download/site-brief-builder.zip) (don't unzip it), then go to Settings > Capabilities > Skills > Upload skill. Also turn on Code execution and file creation.

**Claude Code:**

```bash
git clone https://github.com/NicoSKOOL/site-brief-builder ~/.claude/skills/site-brief-builder
```

## Data

- **Free:** nothing else needed.
- **Better (optional):** the [DataForSEO](https://app.dataforseo.com/?aff=182182) connector fills in competitors and rankings for you.
